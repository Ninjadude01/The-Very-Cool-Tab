# The Very Cool Tab!
I made a website that allows you to view the Astronomy Picture of the Day, using data fetched from NASA (through an API key).
This was built using HTML, css, and Javascript. There is a cool blue sky background, colorful boxes around all items, and a small display that shows the date of the astronomy info.

Additionally, there is a button that when pressed, randomly selects a date and displays the astronomy picture for that day. 
Here is the website link: https://ninjadude01.github.io/The-Very-Cool-Tab/
